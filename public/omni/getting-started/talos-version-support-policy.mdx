---
title: Talos Version Support Policy
description: Omni support policy for Talos Linux versions, end-of-support timelines, and upgrade requirements.
---

Omni requires machines to run a supported version of Talos Linux.
Versions below the minimum supported version are considered **unsupported** and must be upgraded.

For the current minimum supported Talos Linux version and the general support window, see the [Support Matrix](./support-matrix).

## Unsupported Talos versions

Machines running unsupported versions stay connected to Omni, but Omni does not guarantee that it can manage them.
Omni shows warning notifications for machines running unsupported or soon-to-be-unsupported versions.

## Incompatible Talos versions

Starting with the first Omni minor release of 2027 (estimated January 2027), Talos Linux versions below 1.6 will be **incompatible** with Omni:

- Omni will reject their SideroLink connection requests.
- Omni will disconnect them if they are already connected.

Until then, Omni shows a notification for these machines that cannot be dismissed.

### Disconnecting incompatible machines earlier

Omni does not disconnect any machines by default yet.
To disconnect the machines below 1.6 now, set the `--siderolink-disconnect-talos-below` flag:

```bash
--siderolink-disconnect-talos-below=1.6.0
```

or in the configuration file:

```yaml
services:
  siderolink:
    disconnectTalosBelow: 1.6.0
```

## How to upgrade

Follow the [Upgrading Clusters](../cluster-management/upgrading-clusters) guide to upgrade Talos Linux on your machines through Omni.
