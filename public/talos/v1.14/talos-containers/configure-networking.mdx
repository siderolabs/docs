A Talos Container either has no network access or shares the machine's network.
This page explains how to choose between the two, and which ports a container on the machine's network can listen on.
For more information, see the [`ContainerConfig` reference](../reference/configuration/container/containerconfig).

## Choose a network mode

The `network.mode` field sets which network the container uses.

Talos supports two network modes:

- **`none`**: The default. The container gets its own empty network namespace and has no network access.
- **`host`**: The container shares the machine's network namespace. It sees every network interface on the machine, uses the machine's `/etc/hosts` and `/etc/resolv.conf`, and can listen on the machine's IP addresses.

  **Example:** The following document runs a container on the host network:

  ```yaml
  apiVersion: v1alpha1
  kind: ContainerConfig
  name: my-app
  image: registry.example.com/my-app@sha256:...
  network:
    mode: host
  ```

A container on the host network can listen on ports 1024 and higher.
Listening on a lower port also needs the `NET_BIND_SERVICE` capability, as described in [Configure Security](./configure-security#add-or-drop-linux-capabilities).
