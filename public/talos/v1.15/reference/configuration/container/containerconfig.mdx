---
description: |
  ContainerConfig is a container configuration document.
  ContainerConfig declares a container to be run by Talos directly, without Kubernetes.

  The container is started as soon as the configuration is applied, with no image rebuild
  and no reboot. It runs against the CRI containerd instance in the dedicated
  `taloscontainers` namespace, and by default is restarted 5 seconds after it stops.

  Containers are not Talos services: they do not appear in `talosctl services`, and
  `talosctl service` does not apply to them. Status is reported via `ContainerStatus`.

canonical: https://docs.siderolabs.com/talos/v1.14/reference/configuration/container/containerconfig

### healthCheck

ContainerHealthCheck configures a probe which decides whether a running container is healthy.

Exactly one of tcp, http or grpc must be set.




```yaml
lifecycle:
    healthCheck:
        # Probe by sending an HTTP GET request to the port.
        http:
            port: 8080 # Port to connect to on the container's loopback address.
            path: /healthz # Request path.
        interval: 10s # Interval between checks.
        timeout: 1s # Time after which a single check is considered failed.
```
